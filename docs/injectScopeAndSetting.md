# 注入作用域和配置规则

配置分两层：**组 → 位置**。组管顺序和模型作用域，位置管开关和文字。

```
组 1  启用 · 全部模型
  user.prefix            [开]  总是用中文回答
  user.suffix            [关]
  system.personaHead     [关]
  ...（一共 8 个位置）
组 2  启用 · deepseek-account/deepseek-flash
  user.prefix            [关]
  system.last            [开]  回答完用一句话总结
```

## 组

- 每个组有名字、开关、模型作用域、8 个位置块。
- 页面从上到下就是组的顺序，也是同一位置的拼合顺序。
- 组可以新增、改名、上下移、启停、设作用域、删除；删光就是零组。
- 新组默认：启用、全部模型、8 个位置全关、名字「组 N」（N 是当前组数 + 1）。
- 组名输入过程可以空着，保存时还空就恢复成这个组最近一次非空的名字。

## 位置

- 每个位置有开关和一段文字，默认关、空。
- 关着不参与注入；开着但文字为空也不注入。
- 一个组里一个位置只有一块文字，不再有「多条规则」。
- 8 个位置分别落到哪、是替换还是新加，见 [injectPoint.md](injectPoint.md)。

## 拼合

某个位置最终注入什么：

1. 按组顺序从头走到尾；
2. 收下同时满足这四条的组：组启用、组作用域命中当前模型、位置启用、文字非空；
3. 收下的文字按顺序用空行（`\n\n`）连成一段。

一段都没收到就不注入。用户前后缀和 system 六个位置都照这个办法办。

## 模型作用域

- 模型键是 `<provider>/<model>`，比如 `deepseek-account/deepseek-flash`。
- 作用域在组上，管整组的 8 个位置。
- 弹层里「全部」和各模型同列，按 provider 分组，带搜索。
- 点「全部」= 对所有模型生效（含以后新增的），**不清空**其它勾选；取消「全部」之后，之前勾的模型继续生效。
- 既没勾「全部」也没选模型 = 这组不生效，页面胶囊显示「无应用」。
- 失效模型：存过的键在当前目录里找不到 → 标「已失效」并保持勾选，等用户取消；取消前按**不匹配**处理，整组不注入。
- 这份目录跟着 DSH 实时走：在 DSH 里加 / 删 / 改模型，设置页立刻能看到（细节见 [settingGUI.md](settingGUI.md) 的「模型目录什么时候刷新」），不需要重启宿主。
- 某个 provider 的目录没拉全时，列表顶部会说一句，那些没列出来的模型就会显示成「已失效」——不是组坏了。

## 零组和迁移

- 新安装是零组（`groups: []`）：页面居中「还没有注入规则」+「＋ 新建组」，什么都不注入。
- 旧 v1 文件第一次读到时会迁成一个默认组（名字「默认组」，全模型），并留一份 `rules.json.v1.bak`。
- 旧规则各自的模型勾选没法搬到组上，迁移后统一成全部模型。
- 迁移细节见 [userDataUpdateLog.md](userDataUpdateLog.md)，数据结构见 [userData.md](userData.md)。

## 算哪个模型

判据只有一个，两条注入路径（user 前后缀、system 段）共用 `lib/modelRoute.js`：

1. **官方的模型选择投影**（`ctx.sessionProjections` 的 `modelSelection` 单元，键 `pending` → `lastUsed`）。
   这是用户在下拉里点的那个模型，也正是官方 `dsh-agent` 的 `installModelSelection` 用来定路由的状态。
2. 拿不到投影（headless 之类没挂这个单元的组合）→ 会话里**最近一次已提交请求**的路由（`session.requestContext()`）。
3. 再退一步 → agent 建立时的 `options`。

system 段还有更准的一层：`system-prompt/assemble` 拿到的组装结果里，`variables.provider / model`
就是这次组装定下来的路由（官方自己写的），头 / 尾改写优先用它。组的作用域匹配也走这条判据。

## 配置文件

配置文件是 `~/.dsh/dsh-prompt-inject/rules.json`，`.dsh` 目录通过 dsh 宿主获取。文件权限、原子写、坏文件处理和字段说明见 [userData.md](userData.md)。
