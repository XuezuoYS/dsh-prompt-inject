# 注入格式

## 前置词、后置词注入格式

例如，当前有聊天记录：
```
user: user1
ai: ai1
user: user2
ai: ai2
```
假设插件在每一轮用户输入前后都注入，则聊天记录里的用户原文**不改**；前缀和后缀是另外两条 `prompt-inject` 上下文消息，永久留在历史里。到 provider 那边会被合并成：

| role | content |
| --- | --- |
| system | system content |
| user | user1 |
| assistant | ai1 |
| user | user2 |
| assistant | ai2 |
| user | {前置词}user this input{后置词} |

注意：一轮只注入一次；工具循环的续跑请求不重复注入，本轮那份继续留在历史里。注入不会自动清除，所以历史轮次的前后缀也会一直留着（详见 [injectPoint.md](injectPoint.md) 的「用户前置词 / 后置词」）。

## 模板字段

位置的文字里可以写官方的提示词变量，发送时会换成这次请求的真实值。设置页顶栏左侧有个「模板字段」下拉，里面列出全部字段（徽章 + 标签 + 注释）；点一下把 `{{字段}}` 插到你正在编辑的位置输入块（打开菜单不抢输入框的焦点）。没在编辑时按这条链找地方：最近编辑过的位置 → 第一个有文字的组里最后一个有字的位置 → 第一组的用户前置词（自动打开）；一个组都没有就先建「组 1」：

| 字段 | 换成什么 |
| --- | --- |
| `{{model}}` | 这次请求实际用的模型 id，如 `deepseek-flash` |
| `{{provider}}` | 模型属于哪个 provider，如 `deepseek-account` |
| `{{cwd}}` | 当前会话的工作目录绝对路径 |

`model` / `provider` 这两个就是官方在用的提示词变量（官方 persona 头 `You are a coding agent powered by the {{model}} model.` 用的就是它们）；`cwd` 从 0.2.1 起官方不再注册，改由插件自己从会话头（`agent.session.header.cwd`）兜底取，效果一样。**「这一步算哪个模型」与组的作用域匹配走同一条判据**（官方模型选择投影优先，见 [injectScopeAndSetting.md](injectScopeAndSetting.md)）。

渲染时机：

- **用户前置词 / 后置词**：在**注入那一刻**渲染成成品再落进历史。字段当时是多少就是多少，之后不会再变（注入是永久保留的）。
- **system 六个位置**：每个位置先按组顺序拼好，再在 `system-prompt/assemble` 里渲染，然后把这一段标成 `interpolate: false`——官方的插值器不会再看到我们注入的 `{{`。

认不出来、或这次取不到值的字段（名字拼错、没有 agent 的内部调用、值为空）**原样保留** `{{名字}}`，不报错、也不让这次请求失败；名字不合官方规则（中文、大写等）的一律当字面文本。设置页会对「拼错的小写字段」在位置输入块下面给一条轻提示，保存不拦。

要真的写 `{{model}}` 这几个字（不当字段用），写成 `{{ model }}` 或换个大小写就行——那些都不算字段组，会被原样保留。

字段表是**静态白名单**（就是上面那三个，官方桌面部署 0.2.1 只注册 `model` / `provider` 两个，`cwd` 由插件自己兜底），不去反射官方注册表：名字要给人看、还要配注释。别的插件自己注册的变量插件不认，写在正文里会原样保留。
