# 设置 UI 实现

相关：[userData.md](userData.md)（数据模型）、[injectScopeAndSetting.md](injectScopeAndSetting.md)（组与作用域）、[injectPoint.md](injectPoint.md)（注入点）。

## 插件形态

一个 npm 包，两半：

- **host**：cordis 插件（`lib/index.js`），持有配置文件、注入逻辑、HTTP 端点。
- **client**：`package.json` 里声明 `dsh.client = { platform: 'web' }`，浏览器半从 `lib/client.js` 出。

依赖声明成 `peerDependencies`。

## 页面挂载

```js
ctx.slots.inject('settings.section', () => ctx.slots.register({
  name: 'settings.section',
  id: 'promptInject',
  order: 50,
  label: () => 'dsh-prompt-inject',
}, SettingsView))
```

- 挂官方 `settings.section` 槽位 → 设置导航里独立一项，名称就是插件名。
- 只能注册进官方已声明的槽位；自己声明、或抢注未声明的槽位会在加载时报错。
- UI 复用官方 `@deepseek-ai/dsh-client-ui-primitives`（Button / Switch / Input / Checkbox / Modal / Toast）；样式用 `--dsw-*` 设计变量，别写死颜色。0.2.1 起这个包不再随 app 落盘，只作为 web 前端的 baseline 模块存在，浏览器里 `require` 照旧可用。

## 数据通道

host 侧用 `ctx.connection.fetch.register` 在 `/api` 下开端点：

```js
ctx.connection.fetch.register({
  path: '/api/dsh-prompt-inject/state',
  methods: ['GET'],
  requestBody: 'buffered',
  fetch: async (request) => json(await readState()),
})
```

- `/api` 是官方连接层的路由，请求先过 `admit()`（Host/Origin 校验 + 浏览器鉴权）才轮到我们，**鉴权不用自己写**。
- 方法只支持 `GET | HEAD | POST`；`requestBody` 取 `buffered | streaming`。
- 不走官方 typert Remote：那条路要生成产物，运行时不带生成器。

| 方法 | 路径 | 用途 | 请求体 | 响应 |
| --- | --- | --- | --- | --- |
| GET | `/api/dsh-prompt-inject/state` | 组配置 + 模型目录 + revision | — | `{ revision, groups, fields, catalog: { providers, degraded } }` |
| GET | `/api/dsh-prompt-inject/catalog` | 只给模型目录 | — | `{ providers, degraded }` |
| POST | `/api/dsh-prompt-inject/rules` | 覆盖写组配置 | `{ revision, groups }` | `200 { revision, groups, dropped? }` / `409 { revision, groups }` / `422 { issues, dropped }` |

- `catalog` 由 host 现算：`ctx.llm.listProviders()` → `listModels(provider)`，`key` 用 `"<provider>/<model>"`；某个 provider 拉不到就跳过它并把 `degraded` 置真。
- 目录里**没有「当前模型」**：最近活跃会话在多会话并行时未必是你正在看的那个，切换也未必及时反映，
  界面拿它提示只会误导。所以 `/state` 只说「有哪些模型」和「拉全了没有」，界面也就不显示当前模型。
- 写操作带 `revision` 做乐观锁；对不上回 409，客户端提示并重拉，不静默覆盖。
- 写成功后 host 会立刻刷新 system 段的缓存，不需要额外一步。
- **旧客户端**：v1 页面提交 `{ revision, slots }` 时直接回 422，并提示刷新页面；新页面提交的是 `{ revision, groups }`。
- **未知位置键宽容**：位置表里本版本不认识的键就地丢掉，记在响应的 `dropped` 里，**不整包 422**。
  真正非法的内容（组字段、位置文字、模型列表）仍然逐条 422。
- `groups: []` 是合法请求体，零组照常能保存。

## 模型目录什么时候刷新

模型增删改**不用重启 dsh**，也不用刷新页面：host 与界面听的是官方同一套「模型变了」的推送。

| 事件（官方推给浏览器的那几条） | 什么时候响 |
| --- | --- |
| `llm/adapters-updated` | provider 路由增删改（加 provider、改模型列表后适配器重挂） |
| `settings/document-updated` | 任何设置文档落盘（模型设置页就是在写设置） |
| `credentials/record-updated` / `credentials/reference-updated` | 密钥变了，有些模型跟着可用/不可用 |

- **host 侧**（`lib/settingsApi.js`）：事件一响就**丢掉目录缓存**——只丢不清算，没人问就不花这次开销。
  于是客户端紧接着来拉 `/catalog` 时现算，拿到的一定是新目录；30 秒 TTL 只当兜底。
- **客户端侧**（`lib/client.js`）：照同一张表订阅（`ctx.remote.$on`），合并 150ms 后重拉一次 `/catalog`，
  另外在 `connection/reset`（断线重连）后补拉一次。事件表在两边各写一份，`client-shape.mjs` 会对表。
- **只换目录，不动组配置**：`/catalog` 单独开一条就是为这个——设置页的组是本地乐观更新的，
  用户可能正在打字、还没到 500ms 提交，整包重读 `/state` 会把那份编辑冲掉。
- 拿不到 `remote` 服务（极简壳，或网关插件还没挂）时：订阅那部分不激活，设置页照旧能开，
  退回「打开页面时拉一次」的旧行为。老 host 没有 `/catalog`（回 404）时也是留着旧目录，不报错。

## 界面

设置面板里新增一项「dsh-prompt-inject」：

```
dsh-prompt-inject
────────────────────────────────────────────────────────────────────
 [模板字段 ▾]                                            [● 已保存]   ← 悬浮顶栏
 组的顺序就是同一位置的拼合顺序

 ┌ [开关] [组 1          ] (全部)                     ↑ ↓ ✕ ───────┐
 │  ▸ 用户前置词                      [已关闭]                      │
 │  ▾ 用户后置词                                                    │
 │    ┌ 回答完用一句话总结 ──────────────────────────────────────┐  │
 │    │ （留空 = 这个位置不注入）                                │  │
 │    └──────────────────────────────────────────────────────────┘  │
 │  ▸ system 头部                    [替换] [已关闭]                │
 └──────────────────────────────────────────────────────────────────┘

 ┌ [开关] [组 2          ] (已应用 3 个模型)          ↑ ↓ ✕ ───────┐
 └──────────────────────────────────────────────────────────────────┘

 ＋ 新增组
```

零组时页面是居中的空状态：

```
                 还没有注入规则
              点下面按钮建第一个组

                 [＋ 新建组]
```

删除组先弹窗：

```
┌ 删除组「组 2」？ ────────────────┐
│ 删掉后这组的位置和文字都没了。   │
│                      [取消] [删除] │
└───────────────────────────────────┘
```

- **悬浮顶栏**：页面顶栏 `position: sticky` 置顶，滚动设置页时照常可见。它在 `.dshpi-root` 流内排第一位，
  内容区块天然避让它（首屏不会被遮挡）；滚动后内容从其下方滚过，顶栏实心底色不透视。
- 顶栏右侧常驻：**保存状态**（`保存中 / 已保存 / 保存失败`）。**不显示当前模型**——多会话并行时那个值不可信，
  而且组按 `provider/model` 匹配这件事，看卡片上的作用域结论和弹层就够了。
- 顶栏左侧依次是**「模板字段」下拉**和**「全部折叠 / 全部展开」按钮**（有组才渲染）：还有展开的组时按钮写
  「全部折叠」，点一下所有组收起；全部收起了就换成「全部展开」。和单组折叠一样只记页面状态，不保存。
  「模板字段」下拉列出字段表里的每个字段（`{{字段}}` 徽章 + 标签 + 注释），底部一行说明
  插入行为。点字段把 `{{字段}}` 插进目标位置输入块。**焦点契约**：触发钮与菜单项都在 `mousedown` 上
  `preventDefault`，打开与点选全程不抢 textarea 的焦点，插入才落在用户光标处。插入目标的选择链：
  1. 焦点还在某个位置输入框里（常规路径）→ 插在光标处；
  2. 最近聚焦过的那个位置（组和位置都还在）→ 插在它记录的光标处；
  3. 都没试过输入框 → 第一个有文字的组里最后一个有字的位置，追加到末尾；
  4. 还没有 → 第一个组的「用户前置词」，顺带把位置开关打开；
  5. 一个组都没有 → 先建「组 1」，再按第 4 步办。
  打开时点外面（mousedown）或按 Escape 收菜单；老 host 没给字段表时整个下拉不渲染。
  字段表由 host 从 `lib/templateFields.js` 经 `/state` 下发，客户端**不抄一份**；可用的字段与语义见
  [injectFormat.md](injectFormat.md) 的「模板字段」。
- 页面主体是一列**组卡片**，从上到下就是组的顺序。组内 8 个位置按 [injectPoint.md](injectPoint.md)
  的固定顺序排（前置词、后置词、头部 0、950、3050、9800、尾部 10200、10300），**头与尾不挨着**。
- 每个 system 位置行带一枚模式标签：`替换`（改写官方已有那段）或 `插进`（在段位新加一段），颜色区分。
  0.2.1 起官方 persona 尾默认是空串，`system 尾部` 仍按「替换」显示——语义没变，只是替换前本来就是空的。
- **位置折叠**：关着时折叠成一行（开关 + 位置名 + 说明 + 已关闭；system 位置还有 `替换` / `插进` 标签）；打开后出现一个多行输入框。
  位置开着但文字留空，页面给一句「留空 = 这个位置不注入」的提示。
- **组折叠**：组名左侧的小箭头可折叠整组；折叠后卡片只剩头部一行，头部操作（开关 / 组名 / 作用域 / 顺序 / 删除）照常可用。
  折叠状态只记页面（快照里的 `collapsedGroups`），不保存、不进 payload。
- **零组**：页面居中「还没有注入规则」+「＋ 新建组」，不渲染底部的「＋ 新增组」；建出第一组后回到正常列表。
- **组名**：单行输入，输入过程允许清空；保存时还空着就恢复成这个组最近一次非空的名字，页面同步显示恢复后的名字。
- **模板字段**由顶栏左侧的下拉菜单提供（见上面「悬浮顶栏」一条）：字段徽章、注释与点击插入都在那里。
- 位置文字里**拼错的小写字段**（`{{modle}}`）在输入框下面给一条轻提示（`dshpi-card-warn`），保存不拦；
  写中文、大写这类不合官方规则的花括号当字面文本，不给提示。
- **位置里可以带一条提醒**（`notice`）：展开时显示在输入框上方，是一整行会换行的提示块。
  当前只有「用户前置词 / 用户后置词」用它，内容就是那句「注入后不会自动清除、会一直留在历史里」的提醒——
  用户必须在这里就能看到这个代价。提醒文案与 `lib/injectPoints.js` 的 `notice` 逐字一致（`client-shape.mjs` 会对表）。
- 样式只用 `--dsw-*` 设计变量，动效克制（120ms），并在 `prefers-reduced-motion` 下关闭。

## 组卡片

组卡片头部只有一行：`折叠箭头 · 开关 · 组名输入 · 模型结论胶囊 · 已停用标签 · 顺序徽章 · ↑ ↓ │ ✕`。

| 元素 | 行为 |
| --- | --- |
| 折叠箭头 | 折叠 / 展开这组；折叠后位置区收起、只剩头部一行，头部其它操作照常可用 |
| 开关 | 关掉整组不参与注入，页面标「已停用」；位置和文字都留着 |
| 组名 | 单行输入，最多 60 字；输入过程可空，保存时空着就回退到最近一次非空名字 |
| 模型作用域 | 一枚可点的结论胶囊：`全部` / `已应用 N 个模型` / `无应用`；失效的另挂 `已失效 N`。点它开弹层多选 |
| 顺序徽章 / ↑ ↓ | 调整组顺序，首尾自动禁用；这个顺序就是页面顺序和拼合顺序 |
| ✕ | 删除本组，先弹二次确认（取消 / 删除），**所有组都能删** |

组之间没有「复制一整组」；要一样的配置只能手动再建一组。

## 位置行

| 元素 | 行为 |
| --- | --- |
| 开关 | 关着时只占一行，标「已关闭」；打开才出现输入框 |
| 位置名 | 8 个固定位置，顺序见 [injectPoint.md](injectPoint.md) |
| 标签 | system 位置是 `替换` 或 `插进`，跟注入点表的语义一致；用户前置词 / 后置词没有标签 |
| 文本 | 多行输入框，位置唯一的主体；留空等于这个位置不注入 |
| 拼错字段提示 | 小写但拼错的 `{{字段}}` 给一条轻提示，保存不拦 |
| 前后缀提醒 | 用户前置词 / 后置词展开后显示「注入后不会清除」的提醒 |

同一个位置，所有启用组的文字按组顺序用空行连接；不同位置互不影响。

## 模型作用域

- 作用域设在组上，管这一组的全部 8 个位置。
- 弹层里 `全部` 与各模型同列，按 provider 分组（组标题吸附）、带搜索。
- 目录没拉全（`degraded`）时列表最上面给一句说明：没列出来的模型会显示成「已失效」，免得用户以为组坏了。
- 点「全部」**不清空**其它勾选：勾上 = 匹配所有模型（含以后新增的）；取消后，之前勾的模型继续生效。
- **失效模型**：存的 key 在当前目录里找不到 → 置灰标「已失效」，保持勾选等用户取消；取消前按**不匹配**处理（整组不注入）。host 侧同一套规则，界面与行为保持一致。
  目录是实时刷新的（见上面「模型目录什么时候刷新」），所以模型删掉、改名之后，「已失效」会当场冒出来，不用重启宿主去找它。
- 没勾「全部」也没选模型 = 这组不生效，胶囊显示「无应用」并给一句轻提示（具体模型键只在弹层里看，卡片不留）。
- 入口就是组卡片上的那枚胶囊：点它（或它里面的字）开弹层；弹层里勾选立即写回这个组。

## 保存

- 编辑后 500ms debounce 自动提交，请求体是 `{ revision, groups }`；顶部显示「保存中 / 已保存 / 保存失败」。
- 提交前先处理组名：还空着就换回最近一次非空名字，再发。
- 客户端本地乐观更新，写失败或 409 回滚到服务端最新值并提示。
- 422 时把逐条问题展示出来，已有的页面内容不丢。
- 不做显式「保存」按钮。
